# Temporal variability in the diversity, function and resistome landscapes in the gut microbiome of broilers  

This repository contains the scripts and essential files for each analysis section of the project.

- **XX_analysis**: Scripts and necessary files for individual analysis sections
- **r_func**: R functions utilized throughout the project

If you find this code useful, we would appreciate if you cite our paper.
Meng, Jin-Xin et al. "Temporal variability in the diversity, function and resistome landscapes in the gut microbiome of broilers." Ecotoxicology and environmental safety vol. 292 (2025): 117976. doi:10.1016/j.ecoenv.2025.117976
